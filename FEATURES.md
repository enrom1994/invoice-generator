# Zenvoice — Feature List

> **100% Watermark-Free** — Every invoice and quotation you create is clean and professional. No branding, no watermarks, no fine print. Free or Pro.

---

## Free Features

| Feature | Description |
|---------|-------------|
| **Invoice & Quotation Creation** | Create professional invoices and quotations with line items, tax, and totals |
| **3 Templates** | Minimal, Modern, and Compact layouts |
| **PDF Export** | Download invoices/quotations as PDF |
| **Multiple Currencies** | Support for various currency formats and locales |
| **Payment Methods** | Select and display payment method (EFT, Cash, Credit Card, PayPal, Venmo, Crypto, etc.) |
| **Bank Details** | Add bank name, account number, branch code, and payment reference |
| **Client Details** | Enter client name, email, address for each document |
| **Tax Configuration** | Configurable tax name, rate, and toggle |
| **Notes Field** | Add custom notes to invoices/quotations |
| **WhatsApp Sharing** | Share invoices via WhatsApp with a pre-filled message |
| **Email Sharing** | Share invoices via email |
| **Link Sharing** | Copy a shareable link to the invoice |
| **Date Management** | Set invoice/quotation date and due date |
| **Live Preview** | Real-time preview of the document as you edit |
| **Responsive Design** | Works on desktop and mobile devices |
