# 🥇 Concept 1 — Zen Flow Symbol (Recommended)

### Idea

A smooth flowing line forming a **Z + checkmark + document shape**

Represents:

* Flow
* Completion
* Simplicity
* Calm productivity

### Visual Direction

Minimal single-line symbol:

```
Soft curved Z shape
Ending in a checkmark
```

Paired with:

```
Zenvoice
```

### Style

• Rounded edges
• Medium thickness stroke
• Slightly organic curve

👉 This feels modern and premium.

# 🥈 Concept 2 — Minimal Invoice Sheet + Circle Halo

### Idea

A clean invoice/document icon inside a calm circle or halo.

Represents:

* Clarity
* Completion
* Balance
* Zen calmness

### Visual Style

Simple document rectangle with:

✔ One folded corner
✔ One subtle checkmark or line

Circle around symbol = calm / completeness
